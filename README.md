Weather Forecast App shows the weather forecast details for about 5 hours based on the user location.


It offers users to search different location.

It provides an interactive Time to Temparature graphical representation.

Application is designed with few other components makes it more attractive.


# Local Setup :

## Prerequisites

1. Node js installed

2. Node package manager.


## Steps to run the application


1. Clone the repository

```bash
git clone https://github.com/RohanRao143/weather-forecast
```

2. Change to the clone location and now using following command install necessary packages

```bash
npm install
```

3. Run the application

```bash
npm run dev
```



# Integrations :

I have used react hooks to implement the functionality, Redux Slice for API calls and state reducers for application state management.


## Services

Reverse geocoding for location details. https://locationiq.com/geocoding

Search locations and weather forecast. https://open-meteo.com/en/docs
