Weather Forecast App shows the weather forecast details for about 5 hours based on the user location.


It offers users to search different location.

It provides an interactive Time to Temparature graphical representation.

Application is designed with few other components makes it more attractive.


# Local Setup :

## Prerequisites

1. Node js installed

2. Node package manager.


## Steps to run the application


1. Clone the repository

```bash
git clone
```

2. Change to the clone location and now using following command install necessary packages

```bash
npm install
```

3. Run the application

```bash
npm run dev
```




I have used react hooks to implement the functionality, Redux Slice for API calls and state reducers for application state management.

# Redux Toolkit TypeScript Example

This example shows how to integrate Next.js with [Redux Toolkit](https://redux-toolkit.js.org).

**Redux Toolkit**(also known as "RTK" for short) provides a standardized way to write Redux logic. It includes utilities that help simplify many common use cases, including [store setup](https://redux-toolkit.js.org/api/configureStore), [creating reducers and writing immutable update logic](https://redux-toolkit.js.org/api/createreducer), and even [creating entire "slices" of state at once](https://redux-toolkit.js.org/api/createslice). This example showcases each of these features in conjunction with Next.js.
